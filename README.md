# 🌻 FLORES_AMARILLAS

Página web interactiva para una sorpresa especial.

## Ejecutar

No requiere servidor. Abre `index.html` directamente en el navegador.

## Estructura

- `index.html` — estructura principal
- `css/style.css` — diseño y animaciones
- `js/app.js` — interactividad
- `assets/images/` — fotos que añadiremos
- `assets/music/` — música opcional
